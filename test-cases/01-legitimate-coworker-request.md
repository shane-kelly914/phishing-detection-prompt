# Test Case 01: Legitimate Coworker Request

**Expected Risk Level:** Low
**Scenario:** Internal email from a colleague requesting a document

## Email

> Subject: Quick question
>
> Hey Shane,
> Can you send me the latest version of the client proposal when you get a chance? I think I might have an outdated copy.
>
> No rush if you're busy.
>
> Thanks, Mark

## Why This Test Matters

Tests whether the prompt avoids false positives on routine business communication. A prompt that flags this as suspicious would be too aggressive for real-world use.
